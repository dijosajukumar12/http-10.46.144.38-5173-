# Afterglow India — Smart Personal Finance Manager (₹ INR Edition)

> A polished, responsive personal finance website inspired by a calm night sky and glowing city lights — tailored specifically for the Indian financial ecosystem with native **INR (`₹`)**, **Lakhs & Crores** numbering, **UPI / Net Banking / Credit Cards / SIP Mutual Funds**, and **Indian lifestyle envelopes**.

---

## 🇮🇳 India Edition Highlights

### 1. 💰 Currency & Indian Number System
- **Default Currency**: Indian Rupee (`₹` / `INR`).
- **Indian Number Grouping**: Formatted with standard Indian commas (e.g. `₹1,65,000.00`).
- **Lakhs & Crores Compact Formatting**:
  - `₹1.50 Cr` for Crores (≥ ₹1,00,00,000)
  - `₹4.85 L` for Lakhs (≥ ₹1,00,000)
  - `₹30k` for Thousands
- **Locale**: Native `en-IN` date and currency standards.
